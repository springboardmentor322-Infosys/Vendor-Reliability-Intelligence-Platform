## Responsive Breakpoints (Figma Reference)

| Breakpoint | Width | Layout |
|------------|-------|--------|
| Desktop | ≥1024px | Sidebar + content (250px sidebar) |
| Tablet | 768–1023px | Collapsible sidebar |
| Mobile | ≤767px | Bottom nav or hamburger menu |
