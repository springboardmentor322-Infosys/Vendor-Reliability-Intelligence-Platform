# Vendor Reliability Intelligence Platform — Project Objectives

## Vision
Build a centralized platform that helps organizations evaluate vendor reliability, streamline procurement workflows, and make data-driven purchasing decisions.

## Primary Objectives

| # | Objective | Success Metric |
|---|-----------|----------------|
| 1 | **Vendor Reliability Tracking** | Score and rank vendors on delivery, quality, and reliability |
| 2 | **Procurement Workflow Automation** | End-to-end request → approval → purchase order lifecycle |
| 3 | **Role-Based Access Control** | Admin, Procurement Manager, Finance Officer, and Auditor roles enforced |
| 4 | **Unified Dashboards** | Real-time KPIs for vendors, procurement, orders, and performance |
| 5 | **Secure Authentication** | JWT-based login/registration with token expiry |
| 6 | **Responsive UI** | Desktop and mobile-friendly Angular Material interface |
| 7 | **Scalable Backend** | FastAPI + PostgreSQL with clean REST API design |

## Milestone 1 Scope (Week 1–2)
- Define requirements and design artifacts (wireframes, user flows, dashboard layouts)
- Design and implement database schema
- Initialize FastAPI backend with JWT authentication
- Configure PostgreSQL support
- Scaffold Angular frontend with Angular Material
- Implement core screens: Login, Register, Dashboard, Vendor Management, Procurement, Purchase Orders, Performance, Analytics, Reports, Notifications

## Target Users
- **Admin** — Manages users, vendors, and system configuration
- **Procurement Manager** — Creates and tracks procurement requests
- **Finance Officer** — Approves purchase orders and records vendor performance
- **Auditor** — Reviews dashboards, analytics, and compliance reports
