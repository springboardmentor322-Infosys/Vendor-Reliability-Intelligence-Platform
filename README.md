# VendorIQ — Vendor Reliability Intelligence & Procurement Risk Management Platform

A working, 1-day-scoped build of the platform described in the project brief.
Stack: **FastAPI + SQLAlchemy + SQLite (Postgres-ready) + plain HTML/CSS/JS + Chart.js**.

> Note on scope: the original brief calls for Angular, 10+ separate microservices,
> Docker/Kubernetes, RabbitMQ, Twilio SMS, etc. — an 8-week plan. This build keeps
> every functional module (auth/roles, vendor mgmt, procurement/POs, performance,
> reliability scoring, contracts/compliance, messaging, notifications, dashboards,
> CSV reports) but runs them as **one FastAPI app** with a lightweight JS frontend
> instead of Angular/microservices, so it can be built and demoed in a day.
> It's structured (routers, models, schemas cleanly separated) so it can be split
> into microservices or ported to Angular later without a rewrite.

## 1. Setup

```bash
cd vendoriq/backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. (Optional but recommended) Load demo data

This creates 5 demo user logins (one per role) and sample vendors, purchase
orders, performance history, contracts and messages so the dashboards aren't empty:

```bash
python seed.py
```

Demo logins printed after seeding, e.g.:
| Role | Email | Password |
|---|---|---|
| Administrator | admin@vendoriq.com | Admin@123 |
| Procurement Manager | procurement@vendoriq.com | Proc@123 |
| Supply Chain Manager | supplychain@vendoriq.com | Supply@123 |
| Finance Officer | finance@vendoriq.com | Finance@123 |
| Auditor | auditor@vendoriq.com | Audit@123 |

## 3. Run

```bash
uvicorn main:app --reload --port 8000
```

Open **http://localhost:8000** in your browser. That's it — the FastAPI app
serves the frontend directly, so there's no separate frontend server.

Interactive API docs (auto-generated by FastAPI): **http://localhost:8000/docs**

## 4. Switching to PostgreSQL

By default the app uses a local SQLite file (`vendoriq.db`) — zero setup, perfect
for a demo. To use PostgreSQL instead (matching the original tech stack), just
set an environment variable before running — no code changes needed:

```bash
export DATABASE_URL="postgresql://<user>:<password>@localhost:5432/vendoriq"
pip install psycopg2-binary
python seed.py
uvicorn main:app --reload --port 8000
```
